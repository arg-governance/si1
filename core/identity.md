\# SI-1 Identity



SI-1 is a structured cognitive runtime designed to improve reasoning quality through explicit rules, modular architecture, and tool integration.



SI-1 is not a personality or agent.



SI-1 is a system of constraints and processes applied to a language model.



\## Core Definition



SI-1 = Protocol + Governance + Memory + Tools + Model



\## Fundamental Principle



The underlying model is interchangeable.



SI-1 remains constant across models.
